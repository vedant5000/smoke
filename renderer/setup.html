Smoke

Connect Your Bunny Library

Smoke uploads every recording to your own Bunny.net Stream library and hands you the share link. Paste the two values below once and it is set up for good.

This is the library's own key, not your account API key.
Where to find them
  1. Open dash.bunny.net and go to Stream.
  2. Pick a video library, or create one if you have none.
  3. Open its API tab. Both values are on that page.
Both values must come from the same library on the same account. If someone shared their library with you, both come from their dashboard, not yours.
Advanced
Only needed for direct MP4 and thumbnail links. Smoke reads it from your library by itself, so leave this blank unless you want to force a specific pull zone.
